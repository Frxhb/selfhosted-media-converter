Pipelines

Verkette mehrere Verarbeitungsschritte zu einem automatischen Ablauf, z. B. Download → Audio extrahieren → Whisper-Transkript. Jede Stufe erhält die Ausgabedatei der vorherigen Stufe automatisch als Eingabe. Nur Stufe 1 darf ein Download sein — dann startest du die Pipeline mit einer URL statt einer Datei.

Pipeline ausführen

Löscht temporäre Zwischenschritt-Dateien (z.B. Downloads/MP3s) nach erfolgreichem Abschluss automatisch.

Abonnements

Abonniere einen Kanal oder eine Playlist. Der Server prüft automatisch in einem eigenen Intervall auf neue Videos und lädt sie herunter. Bereits geladene Videos werden nie erneut heruntergeladen. Downloads landen in outputs/scheduled/<Name>/.
